# Portfolio Emmanuel — React + Tailwind CSS

## Installation & démarrage

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```

## Structure

```
src/
  components/
    Navbar.jsx     — Navigation glassmorphism
    Hero.jsx       — Section accueil
    About.jsx      — Section à propos
    Skills.jsx     — Compétences + outils
    Work.jsx       — Galerie projets
    Contact.jsx    — Formulaire EmailJS
    Footer.jsx     — Pied de page
    ScrollTop.jsx  — Bouton retour en haut
  App.jsx          — Racine, thème, langue
  i18n.js          — Traductions FR / EN
  index.css        — Tailwind + utilitaires glass
```
